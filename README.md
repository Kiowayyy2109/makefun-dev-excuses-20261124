## The excuse

> It worked on my machine, so we shipped my machine. Production is now my laptop, and my laptop is asleep.

The oldest excuse in software, taken literally: if the code only works
on the developer's machine, the honest fix is to promote that machine
to production — with the entirely predictable consequence that
production now sleeps when the laptop does. One line, 104 characters.

## How to run

```
python3 main.py
```

Prints the line once. Python 3.13, standard library only, deterministic.
